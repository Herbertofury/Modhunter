# ❔ Frequently Asked Questions

### Can I play without MO2?

Yes. The standalone HTML and desktop app load the same offline practice sample. You still have the games and the 227-mod sample checklist. Real Forge Sigils and verified achievements require native MO2 evidence.

### Does MO2 need Electron or the standalone HTML?

No. The plugin includes the dashboard and runs it using its own local server in your normal browser. The desktop app only provides optional integrated tabs.

### Does beating a boss automatically update a mod?

No. A defeated boss offers a precise MO2 link and a pending bounty. You choose and install the update yourself. Rewards are granted only after MO2 confirms a new version.

### Why do some enemies have funny invented names?

Where structured content metadata supplies a real character or item, it takes priority. Otherwise Modhunter makes a clearly identified title-inspired fantasy enemy. It never treats a generated fantasy name as a real ESP record.

### Does the Atlas really have 80 hours?

It defines 480 first-clear challenges whose minimum timers total 80 nominal hours. That's a progression/content target, **not** a claim that 80 hours of unique, finished and playtested authored gameplay exist. The team will judge quality separately from elapsed time.

### Is the live Wiki already synchronized?

The authoritative wiki Markdown is in the repo's `wiki/` directory. GitHub's live Wiki is a **separate Git repository**, so it needs its own first Home page and sync. See the `Sync GitHub Wiki` workflow and `wiki/` README. Repository pages are readable immediately even before the separate Wiki is initialized.
