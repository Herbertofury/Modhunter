## Production gates

The full baseline read and hashed 2,369,967 regular files totaling 2,672,936,357,023 bytes across the mods, downloads, existing MO2 plugins and game files. The independent post-read traversal checked metadata on 2,372,271 regular files across its protected roots and rehashed 14,466 critical files. File membership matched, the NTFS journal ID and cursor stayed unchanged, and there were zero unexplained differences. Private file names, per-mod verdicts, profile state and hashes stay with the operator.

Stock MO2 takes an installation name suggestion. Native installer plugins can change it, choose a merge or replacement, and activate a new mod before Modhunter regains control. Protected installation requests therefore stop before dispatch. The profile-selection path in the installed MO2 build also rewrites an INI, and shutdown can regenerate the profile's tweaked INI. The production profile remained closed for these tests. Real new-mod installation, updating, recovery, production restart and daily-driver promotion need an enforceable solution that preserves those files.
