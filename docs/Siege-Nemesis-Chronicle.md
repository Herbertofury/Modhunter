# Siege rival chronicle

Original optional recurring-rival gameplay, isolated from mod installation and the native reward ledger. On by default for new runs; War Council's Rival Chronicle selector applies to the next run. Existing saved runs without the flag remain standard encounters. Native rival history is losslessly zlib/base64 packed, with no version-history pruning. Browser API state stays JSON. Safety ceilings are 8 MiB decoded history and 750 KB packed combined state; exceeding either reports an explicit save error and retains the previous save. These are limits, not a claim of infinite storage. Offline practice still uses browser localStorage and its quota. State is saved per MO2 profile (or local practice profile) with the existing revision check.

- The exact lethal enemy, not a guessed nearby boss, earns one remembered victory per run. Its mod/version faction returns stronger. Training enemies retain their type identity. No creator is judged or blamed.
- Mod identities include installed and candidate versions. A new candidate/version starts a separate rivalry rather than inheriting a stale accusation. Previous rival records remain retained.
- Strength uses up to five remembered defeats and three weekly observation-age ranks. Each rank adds 12% health and 5% damage; cap rank 8. Movement and attack telegraph timing stay unchanged.
- Age means elapsed span between first and most recent successful observation of that same candidate in Siege. It is not release age, continuously proven outdated duration, vulnerability severity, or crash risk. Missing history remains unknown. Offline time alone cannot increase age; failed requests retain the last good observation. Clock rollback cannot increase it.
- The first defeated champion/boss for each mod/version rival per run drops +4 run XP and +15 hunt score per rank. Training enemies use type-level claims. Duplicate defeat processing cannot pay twice. Victory reduces one remembered-defeat rank. Observed-age challenge remains until the candidate version changes/disappears from the live target roster.
- Run XP/hunt score are simulation-only. Forge Sigils, Chronicle score and verified update rewards are unchanged and remain native-authoritative. The system never updates, changes files, declares a fix, or bypasses the existing exact-file review and installation consent. Keeping a pinned or incompatible mod is allowed without any nongame penalty.

## Acceptance performed
Node unit tests cover missing/malformed timestamps, version isolation, bounded scaling, replay dedupe, disabled runs, observation clock rollback, JSON reload. The existing actual Siege VM harness covers lethal attribution, saved/reloaded rivalry, next-run stronger boss, XP drop/score, duplicate death, redemption and disabled mode. Run full existing JS/Python checks before publication; native WebView2/MO2 gameplay and visual/balance acceptance remain pending while the Windows machine is offline.

## Still open, not silently treated as complete
Realm/Aether and other suitable games need thin adapters and separate acceptance. Verified native update completion bonuses scaling with rival history, author-confirmed issue/fix timestamps, individual named rival traits/escapes/promotions, a richer rivalry journal and cross-mode progression are follow-on scope. Do not inflate this first Siege slice into full cross-game completion. Shared rules live in `nemesis.js`; this follows the existing JS canvas simulation ownership rather than adding a second Rust authority for local-only combat. Rust/native remains the authority for actual downloads/installers and currency.
