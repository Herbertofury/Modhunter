# 🧭 Troubleshooting
[Home](Home.md) / Support

**The HTML opens but shows no MO2 mods:** This is expected in offline practice. Start the MO2 plugin and optionally connect to its loopback URL.

**The desktop starts but cannot reach MO2:** Verify the MO2 Tool is running, copy the displayed exact localhost session URL, and ensure the connection targets `127.0.0.1` rather than an external IP.

**No official Forge Sigils after a battle:** Battle rewards are game-only. A verified real MO2 update is required for official Forge Sigils.

**A displayed version does not match:** Do not assume a name match proves an update. Confirm the exact active profile, mod identity, and source version before taking an installation action.

**No Windows EXE download:** The published desktop artifact is a source ZIP. A native Windows binary has not yet been verified.

**Wiki media or links are missing:** GitHub Wikis are separate Git repositories. The `wiki/` directory in the main repo is the canonical source mirror; use the provided wiki synchronization workflow once the live Wiki has been initialized.
