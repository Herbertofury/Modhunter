# ✧ Rewards & Integrity
[Home](Home.md) / Rewards

**Forge Sigils are official only when MO2 verifies a real update.** The recovered design assigns **10 Forge Sigils per verified update**. Offline or unconnected clients must never mint real maintenance currency.

### Trust boundaries
1. The browser and Electron app are presentation/game clients.
2. The MO2 plugin owns mod identity, profile context and official update authorization.
3. A simulated kill is a game event, not proof that files were updated.
4. Game Embers and legacy perks are distinct from official maintenance rewards.
5. Connectivity loss must degrade to offline practice rather than silently accepting false updates.

### Verification checklist
* A mod appears with the correct identity and active profile.
* An update candidate links to the correct mod, not a similarly named package.
* Installing a candidate follows supported MO2 operations.
* Verified rewards are awarded once per real, verified action.
* Reloading clients does not duplicate awards.
* Removing a browser tab or closing the desktop app never affects the MO2 profile.
