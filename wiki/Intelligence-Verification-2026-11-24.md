## Production gates

The full baseline read and hashed 2,369,967 regular files totaling 2,672,936,357,023 bytes across the mods, downloads, existing MO2 plugins and game files. The independent post-read traversal checked metadata on 2,372,271 regular files across its protected roots and rehashed 14,466 critical files. File membership matched, the NTFS journal ID and cursor stayed unchanged, and there were zero unexplained differences. Private file names, per-mod verdicts, profile state and hashes stay with the operator.

Stock MO2 takes an installation name suggestion. Native installer plugins can change it, choose a merge or replacement, and activate a new mod before Modhunter regains control. Protected installation requests therefore stop before dispatch. The profile-selection path in the installed MO2 build also rewrites an INI, and shutdown can regenerate the profile's tweaked INI. The production MO2 process remained closed for these tests. Real new-mod installation, updating, recovery, production restart and daily-driver promotion need an enforceable solution that preserves those files. [MO2 plugin interface](https://github.com/ModOrganizer2/modorganizer-uibase/blob/edc09d390348244c2e00d189058140bae5d92934/include/uibase/imoinfo.h#L248-L257) · [Native installation callbacks](https://github.com/ModOrganizer2/modorganizer/blob/4ba22f0d8b6f9e08e44008b8395cd774551b4ebe/src/organizercore.cpp#L795-L827)
