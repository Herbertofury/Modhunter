Link your MO2 vault.

01Get the exporter

Save the PowerShell script and inspect it if you like. It only reads each installed mod's meta.ini.

02Run on Windows

Run the .ps1 file in PowerShell. Paste your MO2 Mods folder path when prompted (MO2 toolbar's folder icon).

03Import your exact IDs

Select Skyrim_MO2_Source_Links.json from your Desktop below. Only exact-name matches are linked; existing custom URLs stay untouched.

MO2 metadata may be absent for manually installed files, renamed folders or mods from non-Nexus sites. Unmatched items remain searchable, never silently redirected.

✧ Reconcile renamed folders

When your MO2 folder was renamed, match its real Nexus ID to the correct checklist entry. No fuzzy auto-linking, no wrong-page surprises.

Only choose a match if the imported folder really belongs to that checklist mod. Links are stored locally and included in your progress JSON backup.
