## Exact-file decisions

The full reconciliation covered 11,325 installed mods and 7,244 eligible Nexus project lookups. It reported 6,569 current, 540 newer exact archives, 10 ignored newer versions, 1,729 requiring review, 2,456 unverified, 18 unavailable and 3 unknown. Both the Rust offline importer and an independent read of the original MO2 metadata produced identical verdicts and target file IDs on every row.

The old project-version rule produced 593 update alerts on files now verified current and missed 55 actionable exact successors. Ambiguous branches, incomplete receipts and version-label disagreements on the same immutable file go to review. For AE - Bone Wolf Patch, installed file 252976 on Nexus project 50307 matches Anniversary Edition - Bone Wolf Patch 2.6. Its installed version 2.6.0.0 is equivalent. The separate Alternate Perspective 4.1.0 file has no update relationship to it. [Nexus project files](https://www.nexusmods.com/skyrimspecialedition/mods/50307?tab=files)

Using the installed MO2 version comparator and original persisted metadata, 534 of the 540 actionable exact successors also had MO2's update flag. The remaining six had a distinct provider successor despite a cached no-update flag. Starting MO2's provider refresh can change installed metadata. This comparison used the existing flags and fetched public file evidence separately. ## Full-profile and extraction performance

The controlled full-library import comparison returned equivalent catalog content and warning hashes. Moving the completed catalog data reduced warm median import time from 2,707 to 1,635 ms and p95 from 4,845 to 2,003 ms over 24 warm runs per build. Peak working set including the verification catalog fell from approximately 1.24 GB to 0.905 GB. Concurrent disk hashing and OS caching affected the measurements. The private exact-file benchmark completed five whole reconciliations in a median 2.821 seconds, including result serialization. Its warm post-index provider-row decisions had a worst-run p99 of 0.055 ms. [Full import samples](https://github.com/Herbertofury/Modhunter/blob/main/docs/benchmarks/real-profile-import-20261124.json)

The Chromium extraction comparison covered all 1,200 fixture entries, preserved the output digest and reduced the median from 38.75 to 3.10 ms when ignoring nested regions. Both versions measured 4.2 ms without ignored regions. These figures measure extraction in an existing document. [Region benchmark](https://github.com/Herbertofury/Modhunter/blob/upgrade/verified-intelligence-20261124/native/evidence/watchtower-region-capture-20261124.json)

Scrapy, Playwright and Crawl4AI fetched a 120-entry static or delayed-JavaScript fixture. Each completed comparison verified all 120 titles and links in order and used a different revision on every request. On this Windows host, Playwright's warm median was 59.7 ms static and 86.7 ms dynamic. Crawl4AI completed both at 231.4 and 232.5 ms. The Scrapy HTTP spider completed the static case at 109.3 ms and returned zero of 120 dynamic entries. An empty static extraction therefore requires a renderer for this workload. [Cold, warm and resource samples](https://github.com/Herbertofury/Modhunter/blob/main/docs/benchmarks/extraction-routes-20261124.json)

A separate Linux run compared self-hosted Firecrawl against direct HTTP on all 20 titles and links on a public scraping-practice page. Warm medians were 427.4 and 154.6 ms respectively. The source used pinned public container digests. A Windows changedetection.io 0.70.4 batch completed six checks of the visible book titles and retained one matching snapshot across checks. Its warm worker median was 920 ms, including external HTTP. The changedetection.io text workload and the Firecrawl link workload have separate receipts. ## Production gates

The protected comparison found identical file membership and zero unexplained changes on the production volume, with an unchanged NTFS journal cursor. Private file names, per-mod verdicts, profile state and hashes stay with the operator.

Stock MO2 takes an installation name suggestion. Native installer plugins can change it, choose a merge or replacement, and activate a new mod before Modhunter regains control. Protected installation requests therefore stop before dispatch. The profile-selection path in the installed MO2 build also rewrites an INI, and shutdown can regenerate the profile's tweaked INI. The production profile remained closed for these tests. Real new-mod installation, updating, recovery, production restart and daily-driver promotion need an enforceable solution that preserves those files.
